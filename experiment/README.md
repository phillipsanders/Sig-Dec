# Experiment 1

`Signed Decisions [SIGDEC]_ Preliminary Test Results.fig` is the open record of the first experiment.
Open it in Figma (File › Import, or drag it onto the file browser).

Alongside it are `PROTOCOL.md`, the claim, hypotheses and thresholds fixed on 2 October 2026 before the
first run, and `REPORT.md`, the full report of 5 October 2026. Both are the original documents, unedited.
They refer to files (`runner/`, `scoring/`, commit hashes) that are not published here yet.

In these documents the strictness of a decision is written *working*, *binding* or *mandatory*. That was
the format the agents received. The MUST, SHOULD and MAY wording used elsewhere in this repository came
afterwards.

The Figma file contains:

- **README, Experiment, Results**: the thesis and hypotheses fixed before the first run, the charts of the
  automated checks, evidence taken from the runs, and the conclusion.
- **Deviations and limits, Cost and process data**: where the run departed from the plan, what cannot be
  claimed, and tokens, time and cost per condition.
- **Integrity**: how the run pages were brought into the file and how each was checked against its source.
- **Harbor UI Kit, Harbor Tokens**: the fictional bank's components and tokens every agent was given.
- **31 run pages**, grouped by condition: the screens each agent built, with the agent's own annotations.

The results are preliminary: one model, one task, five runs per condition, no human raters. The verdict
under the pre-registered rule was *adjust*, not *go*. Read "Deviations and limits" before quoting a number.

The run pages are reconstructions of the originals, rebuilt layer by layer and verified against their
sources (2,952 layers, no differences). The Integrity page explains what that check does and does not prove.
